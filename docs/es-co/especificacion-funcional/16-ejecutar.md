# 16. Ejecutar

## Propósito funcional

Este documento describe las operaciones de ejecución del proyecto y el resultado esperado de cada una. Los comandos y las instrucciones técnicas correspondientes se encuentran en [Ejecutar de la especificación técnica](../especificacion-tecnica/18-ejecutar.md).

## Servidor de desarrollo

Permite consultar el sitio en un navegador durante el desarrollo local. El servidor ofrece la aplicación en `http://localhost:4200/` y la recarga cuando se modifican los archivos fuente.

## Andamiaje de código

Permite generar elementos del proyecto, como componentes, y consultar los esquemas disponibles mediante la ayuda de Angular CLI.

## Construcción del proyecto

Transforma el código fuente en los artefactos de construcción de la aplicación. Los archivos generados se almacenan en `dist/`.

La construcción de producción optimiza la aplicación para su rendimiento y distribución.

## Pruebas unitarias

Permiten comprobar el comportamiento de las unidades del proyecto mediante Vitest. Su ejecución complementa los requisitos definidos en el documento de validación y pruebas.

## Pruebas de extremo a extremo

Permiten comprobar los flujos de la aplicación mediante el entorno de pruebas de extremo a extremo configurado en el proyecto.

## Referencia de comandos

El archivo [ejecutar.md](../../ejecutar.md) conserva los comandos de ejecución del proyecto como referencia independiente.
